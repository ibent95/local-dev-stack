code-review-graph reports

Interactive D3 graph exports from lds tools crg <path> land in the per-repo folders listed below (browse the directory index). The graph is local-first — nothing leaves your machine.

Browse report folders

No report yet? Generate one:

  • lds tools crg ~/projects/myapp — build the graph + export the report
  • lds tools crg ~/projects/myapp myapp — custom name for the viewer URL
  • open http://crg.test/myapp/ — the interactive graph

The scan also writes .code-review-graph/ (graph DB, gitignored) inside the scanned repo, so re-scans are incremental. AI integration via MCP is optional and runs on your host: pip install code-review-graph && code-review-graph install.

Start the viewer with lds up crg.
